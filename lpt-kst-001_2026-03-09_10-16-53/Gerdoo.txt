Adobe Acrobat Pro DC 2018.011.20035
===================================

<<Installation Guide>>

*Disconnect internet.

*It's better you install this software in fresh windows.Uninstall the previous versions.

Install the Program.

1- In "Folder Location" window click on "Next" button for extract data in your system.

2- In "File Are Ready" window click on "Finish" button.

3- In "Serial Number" window check "Use trial or subscription" option .

4- Complete installation levels.

5- In "setup Completed" window click on "Finish" button.

6- Install "Update.msp" file from "Gerdoo" folder.

7- Run "Gerdoo.exe" from Gerdoo folder.

8- Copy "Patch.exe" file from there to installation directory,then run it.

32bit: C:\Program Files\Adobe\Acrobat DC\Acrobat
64bit: C:\Program Files (x86)\Adobe\Acrobat DC\Acrobat

9- Choose "Adobe Acrobat DC" from the list of product then click on "Install" button.

10- Choose "amtlib.dll" file from installation path then click on "Open" button.

11- Run "Patch.bat" file from there and press any key . Now you can use this program.(Run as administrator in windows 8.1)

12- Run program goto "Edit--->Preferences--->Updater" then uncheck "Automatically install Update" option and click on "OK" button.
